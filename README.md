# Machine Learning Based Buyer Segmentation and Investment Profiling

This project uses Machine Learning to segment real estate buyers based on their demographic, financial, and property preferences.

## Features

- Data preprocessing
- Exploratory Data Analysis
- Buyer segmentation
- Investment profiling
- Data visualization
- Machine Learning
- Interactive Streamlit dashboard

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Project Objective

The main objective is to identify different types of real estate buyers and provide useful insights for real estate market intelligence and investment decision-making.
